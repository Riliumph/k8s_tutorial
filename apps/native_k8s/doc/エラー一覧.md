仮想環境の場合は、気をつけなければならない。  
このswapが仮想環境外からマウントされているものであれば、ホストのswap設定を変える必要があるからだ。

```console
root@k8s-master:/# cat /proc/swaps
Filename   Type        Size      Used      Priority
/dev/sdc   partition   4194304   1323488   -2
-------------------------------
vscode@devcontainer:/workspaces/apps/native_k8s| (kubeadm *%)
$ cat /proc/swaps
Filename   Type        Size      Used      Priority
/dev/sdc   partition   4194304   1316456   -2
```

同じswapを見ているので、`/dev/sdc`は共有のデバイスを見ている。  
Kernelを共有する都合上、仮想環境だけというわけにはいかないので、ホストのswapを停止する。

```console
$ sudo swapoff -a
```

#### 仮説1

rootがoverlayなのに、その上でk8sはoverlayFSのファイルシステムをmountしようとしている。

#### 仮説2
